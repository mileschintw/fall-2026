# 排程任務的共同收尾（每個任務最後都要做）

目的：讓使用者只看一個地方 `digests/INDEX.md`，就知道每次排程跑了什麼、有沒有新東西。

1. **登記到 `digests/INDEX.md`**。在「## 紀錄」標題下方的表格**第一列（表頭和分隔線之後）**插入一列，最新的在最上面：
   `| <MM/DD 週X HH:MM> | <任務名> | <狀態> | <一句話重點> | <輸出檔連結> |`
   - 任務名：晨報、週規劃、截止提醒、上課筆記。
   - 狀態：
     - ✅：正常完成
     - 🆕：完成，而且有新東西（新公告、新作業、新錄影、新筆記、有推播的提醒）
     - ⏭：跳過，例如錄影尚未發布、沒有到期項目
     - ⚠️：部分來源失敗或需要重新登入
     - ❌：失敗
   - 一句話重點：最多 60 字，寫具體內容，例如「A3 剩 24h；Piazza 新 2 篇（老師答 @47）」。沒有新東西就寫「沒有新東西」。
   - 輸出檔連結：用相對於 `digests/` 的 Markdown 連結，例如 `[2026-10-19.md](2026-10-19.md)`、`[notes](../dsa/lectures/2026-10-19/notes.md)`。沒有輸出檔就寫 `—`。
   - 用 Edit 插入，不要重寫整個檔案，也不要刪掉舊的列。
2. **更新 `digests/INDEX.md` 最上方的「最新狀態」區塊**，只改自己任務那一行：最後一次執行時間、狀態、輸出檔連結。
3. **推播**：狀態是 🆕、⚠️、❌ 時，用 PushNotification 送一則：`[<任務名>] <一句話重點>`。✅ 和 ⏭ 不推播（截止提醒照它自己的規則推播，這一步不重複送）。PushNotification 可能因為使用者正在用電腦而沒送出，這沒關係，INDEX.md 才是正本。
4. 不 commit、不 push。

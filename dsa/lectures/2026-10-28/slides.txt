Balance factor   of a node = height of its left subtree − height of its right subtree. (A single
node has height 0; the empty tree has height −1.)

5. Why the height is O(log n) 
N(h) = the   fewest   nodes an AVL tree of height h can have. N(h) = 1 + N(h − 1) + N(h − 2). 
Height h   0   1   2   3   4   5   6   7   8 
Fewest nodes N(h)   1   2 
So an AVL tree with n nodes has height at most __________, which is O(log n). 
6. Asymptotic notation 
f(n) is   O(g(n))   if there are constants c > 0 and n 0   such that f(n) ≤ c · g(n) for every n ≥ n 0 . 
f(n) is   Ω(g(n))   if f(n) ≥ c · g(n) for every n ≥ n 0 . f(n) is   Θ(g(n))   if both hold. 
Notation   Reads as   Means 
f is O(g)   at most   past some point, f ≤ c · g 
f is Ω(g)   at least   past some point, f ≥ c · g 
f is Θ(g)   exactly, up to constants   c 1   · g ≤ f ≤ c 2   · g 
Example.   Show that f(n) = 3n 2   + 5n + 2 is O(n 2 ) by finding a c and an n 0   that work. 
f(n) = 3n² + 5n + 2 compared with 3n² and 4n². 
Rules of thumb.   Drop constant factors and lower-order terms. The base of a log does not
matter. Slowest-growing first: 1, log n, n, n log n, n 2 , n 3 , 2 n . 
Careful:   O is not the same thing as "worst case."

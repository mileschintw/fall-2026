2. Tier 0 Baseline

Unmodified starter (direct conv, FP32), built for sm_75 + sm_86 and run on our own GPU (NVIDIA GeForce RTX 3050, 8 GB) on the dev set (500 images) with check.py --iters 3 --warmup 1: 12.0 images/s at batch 32 (median 41,686 ms per pass) and 11.9 images/s at batch 64. The correctness gate passes (top-1 / top-5 error 19.20% / 3.20%, identical to the reference; top-1 agreement 100%). The course T4 figure for the same starter is 18.5 images/s (full val set). Each stage-4 conv performs the same MACs as a conv in the other stages but runs about 5× slower (64 vs. 13 ms per MMAC). The direct conv runs one thread per output with Cout fastest, so neighbouring threads stream different filter rows; with a 9.4 MB filter and a serial K = 4,608 loop the weight reads likely stop hitting in cache and the kernel becomes memory-bound (to be confirmed in Nsight Compute). Batching alone does not help the starter (12.0 vs. 11.9 images/s); it starts to matter once the GEMM path tiles over M = B·Hout·Wout.

3. Planned Tiers and Batch Size

We target Tier 2 by the design specification (2 Dec) and Tier 4 (FP16 tensor cores) by the leaderboard freeze (15 Dec), with Tier 5 items as stretch goals. We will hold entries in both the FP32 and FP16 categories. Targets will be revised as measurements come in.

TierContentTarget date
T0Unmodified starter, smoke-test submission22 Nov
T1im2col + SMEM-tiled SGEMM, fused bias/ReLU epilogue28 Nov
T2Implicit GEMM (gather in tile load), fused residual add, per-shape launch configs2 Dec
T3Register tiling, float4 loads, tile sizes tuned per shape class8 Dec
T4FP16 WMMA / mma.sync (m16n8k8) with FP32 accumulation13 Dec
T5 (stretch)Stem conv + maxpool fusion, shared downsample read, warp-shuffle avgpool/top-515 Dec

Batch size. Tier 0 uses batch 32 (the starter is insensitive to it). From Tier 1 on we plan batch 64. Stage 4 has only M = 49 rows per image, so at B = 64 its GEMM is 3,136 × 512 and a 64 × 64 tile grid gives 392 blocks, about 10 per SM on the T4's 40 SMs (200 blocks at B = 32). The cost is memory: at B = 64 the explicit im2col A matrix of a stage-1 conv is 200,704 × 576 × 4 bytes ≈ 462 MB, which fits in 16 GB but is the bandwidth-bound traffic that Tier 2's implicit GEMM removes. 500 dev images = 7 × 64 + a tail batch of 52. Miles will sweep B ∈ {32, 50, 64, 100, 128} at each tier and declare the fastest valid one in submit.py.

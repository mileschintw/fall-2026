Array vs Linked list

Array：一塊 contiguous 記憶體、同型別、fixed size。第 i 個的位址 = 起點 + i × 大小，所以 index 存取 O(1)。size（放了幾個）≠ capacity（配置了幾格）。

Class 1 p23–29、Class 2 p3

Linked list：node = data + next pointer，散在記憶體各處。只知道 head，找第 k 個要從 head 走。metadata（size、tail）讓某些操作變快，代價是每次都要記得更新。

Class 4–5 · 10/12、10/14

Dynamic array、amortized、Python list

Python list 是 resizable array of references（pointers）：連續記憶體裡每格存一個 8-byte 的 pointer，物件本身放在別處。所以能混放型別，lst[i] 仍然 O(1)。Class 4 [01:43:41]、Class 5 [00:13:09]

互動：滿了要長多少？數「複製了幾個元素」

初始 capacity 5，滿的時候把 size 個元素搬過去。n=100 時三個數字跟老師課堂跑的一樣（約 5,000／500／155）。長條是 log 刻度。Class 4 [01:10:12]–[01:28:26]

Amortized O(1)

一次 O(n) 的 resize 換來後面一大堆 O(1) 的 push。Doubling 時每次 grow 搬 5+10+20+…+c < 2c 個，c < n，所以 n 次 push 總共搬不到 2n 次，平均每次不到 2 次。

Amortized 是對一整串操作的總量保證，不是對隨機輸入取平均。

Tree 與 Traversal

Binary tree 是 recursive 定義：要嘛是 empty，要嘛是一個 node 帶一棵 left tree 和一棵 right tree。Base case 就是 empty（None）。Linked list 是每個 node 只有一個 child 的特例（degenerate tree）。Class 6 [00:38:04]–[00:44:02]

名詞：root、leaf、parent／children、sibling、path、depth（root = 0）、level、height。

Height 數 edges：單一 node = 0，空樹 = −1。有些書數 nodes（1 和 0），題目會選一邊，看清楚。高度 h 最多 2h+1−1 個 node；100 萬個值至少 height 19。Class 6 [00:45:06]、講義 p3、p9

Binary Search Tree

BST 規則：for every node，left subtree 裡每個值都比它小，right subtree 裡每個值都比它大。老師要的是「樹的性質」，不是「比較小就往左」這個演算法；也不是只看 child。Class 8 [00:30:01]–[00:35:00]

AVL tree

Balance factor(node) = height(left subtree) − height(right subtree)。正 = left heavy，負 = right heavy。

AVL tree = 每個 node 的 balance factor 都是 −1、0 或 1 的 BST。所以每個 AVL 都是 BST，反過來不一定。

Insert 之後只有「新 leaf 到 root 這條路徑」上的 node 高度會變，只要從下往上檢查它們。壞掉的 node 一定是 ±2（每次插入都馬上修）。

Class 9 [00:49:02]–[01:02:06]、Class 10 [01:10:00]–[01:29:07]

x 升上來，y 變 x 的 right child，B 從 x 的右邊搬到 y 的左邊。前後由左到右都是 A, x, B, y, C → inorder 不變 → 還是 BST。只改三個 link，O(1)。Left rotation 是鏡像。Class 9 [01:06:01]–[01:12:02]

Class 9–10 · Asymptotic analysis

Big-O

f(n) = O(g(n))：存在常數 c > 0 和 n₀，使得所有 n ≥ n₀ 都有 f(n) ≤ c·g(n)。f = 程式執行的 operation 數（以 n 表示），g = 拿來比的函數（1、log n、n、n log n、n²、n³、2ⁿ）。Class 9 [01:27:17]、Class 10 [00:13:00]–[00:16:00]

互動：找 c 和 n₀

考試要會的算法

例 f = 3n²+4n+3、g = n³，找 C：n ≥ 1 時 3n² ≤ 3n³、4n ≤ 4n³、3 ≤ 3n³，相加得 f(n) ≤ 10n³ → C = 10、n₀ = 1。也可以用滑桿找更小的 C，只要「存在」一組就好。

例 3n²+5n+2 = O(n²)：n ≥ 6 時 5n+2 ≤ 6n ≤ n²，所以 f ≤ 4n² → c = 4、n₀ = 6。c = 3 不行（要 5n+2 ≤ 0）。n = 5 時 102 > 100，這就是為什麼要 n₀。

不成立怎麼寫：3n²+5n+2 ≤ c·n ⇔ 3n + 5 + 2/n ≤ c，左邊隨 n 無限長大，沒有常數 c 擋得住。

Class 9 [01:29:01]–[01:39:00]、講義 p6–p7、Class 11 [01:33:09]

捷徑與陷阱

  • 丟掉低次項，再丟掉係數：2n² + n + 5 → O(n²)。直接看最重的那層迴圈（dominates）。
  • 成長順序：1 < log n < n < n log n < n² < n³ < 2ⁿ。log 的底數不重要。
  • O 是 upper bound：n² 是 O(n³)、O(n⁶)，技術上都對；面試要給 tight bound（Θ）。
  • O 不是 worst case：BST search 的 worst case 是 Θ(n)，random 插入的 average case 是 Θ(log n)，AVL 的 worst case 是 Θ(log n)。
  • 2ⁿ⁺¹ = 2·2ⁿ 是 O(2ⁿ)；2²ⁿ = 4ⁿ 不是 O(2ⁿ)。
  • n = 10⁶、每步 1 ns：n 步 1 ms，n² 步約 17 分鐘。

def push(stack, x):
    if stack['size'] == len(stack['data']):
        raise IndexError('Stack is full')   # 或 resize
    stack['data'][stack['size']] = x
    stack['size'] += 1

def pop(stack):
    if stack['size'] == 0:
        raise IndexError('empty')
    x = stack['data'][stack['size'] - 1]
    stack['size'] -= 1
    return x

def resize_double(stack):

    stack['data'] = new

def push(stack, x):
    node = {'payload': x, 'next': None}
    node['next'] = stack['head']   # 先讀
    stack['head'] = node           # 再寫
    stack['size'] += 1

def pop(stack):
    if stack['size'] == 0:              # 少了這行 → NoneType 錯
        raise IndexError('empty')
    node = stack['head']
    stack['head'] = node['next']
    stack['size'] -= 1
    return node['payload']

    cur, index = stack['head'], 0
    while cur is not None:
        if cur['payload'] == value:
            return index
        cur = cur['next']
        index += 1                      # 老師第一版漏了

def bfs(root):
    out, todo = [], deque()
    if root is not None:
        todo.append(root)
    while todo:
        node = todo.popleft()           # FIFO
        out.append(node['payload'])
        if node['left'] is not None:  todo.append(node['left'])
        if node['right'] is not None: todo.append(node['right'])
    return out

    if root is not None:
        todo.append(root)

    return out

def bst_search(root, value):

# BST delete（A5 Part 1 的寫法，回傳新的 subtree root）
def bst_delete(node, value):
    if node is None:
        return None
    if value < node['payload']:
        node['left'] = bst_delete(node['left'], value)
    elif value > node['payload']:
        node['right'] = bst_delete(node['right'], value)
    else:
        if node['left'] is None:        # 0 或 1 個 child
            return node['right']
        if node['right'] is None:
            return node['left']
        succ = bst_min(node['right'])   # 2 個 child
        node['payload'] = succ['payload']
        node['right'] = bst_delete(node['right'], succ['payload'])
    return node

def rotate_right(y):
